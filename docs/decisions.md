# Decisions — basecast-airflow

One line per decision: date, decision, reason. Cross-repo decisions live in `basecast-get-data`.

- 2026-09-25 — Raw phase first: every source only discovers and downloads into `raw/`; parsers come next. — Get all public data secured before files age out of ERCOT's windows.
- 2026-09-25 — ERCOT report listings come from the product page itself: `data-product-details?id=<EMIL>` declares `reportTypeID`, `reportListUrl` (`misapp/servlets/IceDocListJsonWS`) and `reportDownloadUrl` (`misdownload/servlets/mirDownload`) in its inline script; we parse those, no login. — Verified on PG7-200-ER and NP6-345-CD; no URL is constructed by hand.
- 2026-09-25 — ERCOT Public API credentials are not needed for the raw backfill. — The listing service above serves the full GIS history (Apr 2019 → Aug 2026) and the other products we need.
- 2026-09-25 — Legacy `mis.ercot.com/misapp/GetReports.do` is not used. — It now requires a client certificate (SiteMinder).
- 2026-09-25 — `ercot_gis` also takes the co-located battery identification reports (same Report Type 15933, 72 files since Nov 2020). — Cheap (~33 MB) and relevant to storage; parsers can ignore them for now.
- 2026-09-25 — `ercot_gis` also takes the older monthly GIS workbooks still linked from the Resource Adequacy year pages (May 2014 – 2018, 60 files). — Five more years of queue history for the survival model; not in the ERCOT listing.
- 2026-09-25 — `dt=` convention: report-series files use the date the source assigns (GIS: first day of the report month; NP6-345-CD and SPP history: publish date in America/Chicago); everything else uses the fetch date in America/Chicago. — Reproducible snapshots; the current-year files ERCOT overwrites land in new folders.
- 2026-09-25 — One `_manifest.json` per `dt=` folder, appended as files land; raw files are never overwritten (a same-day content change is stored with a `__<sha8>` suffix). — Immutable raw with provenance, crash-safe.
- 2026-09-25 — Idempotency order: known ERCOT document id → skip without request; immutable URL already fetched → skip; conditional GET with stored ETag/Last-Modified; identical sha256 → discard. — ercot.com serves ETag and Last-Modified, so re-runs are cheap.
- 2026-09-25 — HTTP: 20 req/min on ercot.com (30 elsewhere), evenly spaced; retries on 429/5xx/network errors with jittered exponential backoff and `Retry-After`; the run aborts after 6 consecutive failures. — Runbook politeness rules; ERCOT has suspended keys for high failure rates.
- 2026-09-25 — Default User-Agent has no personal contact (`basecast-pipelines/0.1 (Base Power x AITX hackathon; public data research)`), overridable with `BASECAST_USER_AGENT`. — Identifiable without publishing an email.
- 2026-09-25 — `ercot_native_load` takes years ≥ 2003 only. — Weather zones start in April 2003; earlier files use control areas (out of the MVP).
- 2026-09-25 — `ercot_ltlf` takes every file under the long-term sections of the Load Forecast page and its year pages (2013–2025), skipping Mid-Term sections; the weather-year scenario workbooks are an option (`--opt include_weather_scenarios=true`). — Full vintage history for the backtest while keeping the source under ~1 GB.
- 2026-09-25 — `ercot_cdr` takes every spreadsheet in the CDR sections of the Resource Adequacy page and its year pages (2000–2025), PDFs optional. — Many forecast vintages for the backtest; the spreadsheets carry the numbers.
- 2026-09-25 — `census_acs` uses the ACS table-based Summary File (`acsdt5y<year>-b25032.dat` + table shells) instead of the Census Data API. — The API now requires a key for data queries; the summary file needs none.
- 2026-09-25 — `eia_territories` reads the ORNL-hosted ArcGIS copy of the HIFLD layer (item `597555ce8e4a4892a030784a7c657fdd`, frozen 2025-08-21), querying by Texas bounding box at full precision in pages of 25. — The EIA Atlas page in the catalog returns 404; `STATE` is the mailing state, so a spatial filter catches out-of-state utilities.
- 2026-09-25 — `eia_861` takes final releases since 2013 plus the latest early release. — Utility-level sales history to spot growing co-ops and munis, still a modest download.
- 2026-09-25 — `open_meteo` requests ERA5 (`models=era5`), `temperature_2m` and `dew_point_2m`, per point and year, in GMT. — One consistent reanalysis across 2003 → today (the default "best match" blends models that change over time); dew point matters for cooling load.
- 2026-09-25 — `ercot_large_load_decks` crawls the TAC, LLWG, LFLTF, Board and R&M committee pages (roots + year pages from 2024), every meeting page reachable from them (meeting pages link their neighbours, which finds LFLTF 2025), and Helpful Resources for ERCOT Monthly; TAC agenda-item zips are downloaded only when a member name matches (member list read with one byte-range request). `dt` = meeting date. — The status deck moved and was renamed three times since 2024; no data product exists (NPRR1267 report not found in EMIL).
- 2026-09-25 — Large-load "other" material is kept only from Board/R&M pages, TAC zips and Helpful Resources, not every LLWG document. — LLWG pages are almost all large-load policy documents; the model needs the status decks and headline numbers.
- 2026-09-25 — Weather points = the reference cities in Figure 1 of ERCOT's 2025 LTLF report (12 cities), at each city's primary airport (NOAA ISD coordinates), equal weights within each zone. — ERCOT does not publish its station list or weights in the report; this is the closest documented choice.
- 2026-09-26 — `ercot_ltlf` also took the weather-year scenario workbooks (8 × ~72 MB); the source totals 871 MB. — The user asked for all data; still under the ~1 GB per-source limit.
- 2026-09-25 — Open-Meteo is paced at 3 requests/min. — A one-year hourly request counts as ~26 calls; the free tier caps at 5,000/hour and 10,000/day. Free tier is non-commercial only: fine for the hackathon, needs a paid plan or ERA5 from Copernicus for commercial use.
- 2026-09-26 — Added 18 raw sources found by the overnight research pass (`docs/source-research-2026-09.md`): PUCT CCN territories, directories and large-load filings; ERCOT TPIT, RTP, NP4-160-SG, NP12-215-ER, members, Demand and Energy, Fuel Mix; EIA-860M/860; PUDL; NOAA GHCNh; Census PEP; BLS QCEW; TCEQ air permits; Texas Comptroller agreements. — The user asked to scrape everything mapped and then research more; each adds a signal the original runbook lacked (official territories, TSP large-load requests, pre-construction permits, license-free weather).
- 2026-09-26 — `ercot_fuel_mix` downloaded now. — The runbook left it for after A9 (prices + MORA), which is done.
- 2026-09-26 — `eia_860m` takes the latest month plus every December by default; all ~130 months are an option. — PUDL's EIA-860M changelog already carries every monthly status change; full history is ~1 GB.
- 2026-09-26 — `tceq_air_permits` keeps only program AIRNSR rows (~690k of 4.3M) from the five Central Registry datasets. — Air permits are the data-center signal (backup generators); other programs are noise for us.
- 2026-09-26 — `pudl` is pinned to release v2026.9.0 and takes 8 tables only. — Reproducible and small; the full bundle is 12.7 GB. CC-BY-4.0 requires attribution in the app.
- 2026-09-26 — `noaa_ghcnh` downloads the 12 airport stations 2003 → today as the license-free weather series. — ISD stopped updating in 2025 and Open-Meteo's free tier is non-commercial.
- 2026-09-26 — Personal data present in public files (TPIT contacts, NP12-215-ER representatives, PUCT directory contacts, Ch. 380 officers, RTP staff emails) stays in raw as published and must be dropped at parse. — Raw is an immutable copy; nothing personal goes to Parquet or the API.
- 2026-09-26 — LBNL "Queued Up" is not automated. — emp.lbl.gov and eta.lbl.gov answer with a Cloudflare challenge (403); it needs a manual browser download.
- 2026-09-26 — All 10 figures in `config/manual_official_figures.yaml` checked against the raw documents and marked verified, with URL and page. The March 2026 observed peaks of approved large loads are 4,004 MW (non-simultaneous) and 3,522 MW (simultaneous), from ERCOT's updated deck of 2026-03-26; the 3,883/3,801 MW in our docs came from the 2026-03-12 PDF, which labels them "March 2025". — Numbers shown to judges must match the latest source.
- 2026-09-26 — The 58777 item 38 table is TSP large-load *requests* (RFI submissions), not a forecast: 11,443 MW (2026) → 242,999 MW (2032). PPTX and PDF match; rows by type sum to the totals, rows by TSP differ by ≤1 MW from rounding. — Framing: "243 GW requested; the model says how much becomes load."
- 2026-09-26 — `puct_filings` takes every document of every item of dockets 58777, 59772 and 58481 (was: the index plus 5 chosen items). Documents are immutable (id in the name), so re-runs only fetch new items. — The user asked for the full available history.
- 2026-09-26 — TCEQ data-center signal is defined by a reproducible filter: AIRNSR rows whose `reg_ent_name` matches `DATA ?CENTER|DATACENTER|DATA CTR` or whose `indus_typ_cd` is 518210, deduplicated by `ref_num_txt`, dated by the earliest `affil_begin_dt`. It gives 88 sites; 37 have a first permit since 2025, in 26 counties, 34 of them outside the big metros. — It is a lower bound (misses sites not named "data center", e.g. crypto or project code names) with no MW; the earlier "many rural counties" claim came from sampling.
